¿Dónde la encuentras en SimpliRoute?
Una visita subida por API NO aparece sola en una ruta o chofer — SimpliRoute la deja primero "sin planificar". Pasos:
  1. Entra a Monitoreo (Monitoring) → pestaña Visitas → elige la fecha : ahí SÍ aparecen todas, aunque no tengan ruta asignada.
  2. Para asignarla a un chofer: módulo Router → abre o crea el plan de esa fecha → paso 2 "Visitas" → opción "Desde integración" (la API las dejó ahí, no se cargan solas al plan) → paso 3 "Rutas" → optimizar o arrastrarla manualmente a un vehículo.
