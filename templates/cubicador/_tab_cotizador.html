Logística ILUS
Cotizador de envíos

Compara en una sola pantalla lo que cobra cada courier por este envío. El precio más bajo con tarifa confirmada queda destacado; las estimaciones del sistema se muestran marcadas y nunca se recomiendan.

Datos del envío
Escribe y elige la comuna sugerida por Google para evitar errores de tipeo.
kg
Peso facturable (el mayor entre el real y el volumétrico).
$
Se usa para calcular el seguro de la carga.
Datos tomados de —
De dónde sale cada precio
  • Tarifa ILUS Sale del tarifario negociado que ILUS tiene cargado para esa comuna.
  • API El courier respondió en línea con su propio precio para este envío.
  • Estimado No es una tarifa confirmada. El courier no tiene precio cargado para esa comuna y el sistema calcula una referencia. Confírmala antes de comprometerla con el cliente — por eso jamás aparece como recomendada.
  • Validada La tarifa fue contrastada a mano contra el Excel maestro.
